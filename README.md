# TravelAgentDark (Red-Eye)

An overnight travel agent for small teams. It finds trips in your Slack and email, follows your travel policy, watches fares while you sleep, books with one-time virtual cards, and learns from every night.

Built at **Agents After Dark**, UC Berkeley Build Night (Nov 16, 2026), using **Cognee** for memory and **Allowance** for agent payments.

See **[BUILD_PLAN.md](BUILD_PLAN.md)** for the full plan: architecture, how Cognee and Allowance fit in, timeline, demo script and judge Q&A.
