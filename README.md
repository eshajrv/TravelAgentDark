# TravelAgentDark (Red-Eye)

An overnight travel agent for small teams. It finds trips in your Slack and email, follows your travel policy, watches fares while you sleep, books with one-time virtual cards, and learns from every night.

Built at **Agents After Dark**, UC Berkeley Build Night (Nov 16, 2026), using **Cognee** for memory.

Payments use **Stripe Link** (a mock backend by default; set `PAYMENTS_BACKEND=link` in `.env`).

See **[BUILD_PLAN.md](BUILD_PLAN.md)** for the full plan: the final stack and priority order, architecture, how Cognee and Stripe Link fit in, timeline, demo script and judge Q&A.
